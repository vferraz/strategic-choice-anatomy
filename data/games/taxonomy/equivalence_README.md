# Equivalence dataset — Bruns/Robinson-Goforth + Nagel + clean Griffiths

Generated by `scripts/build_equivalence_dataset.py`. All three CSVs share the
same definition of CLEAN Griffiths game:

> A Griffiths game is CLEAN when its cardinal payoffs preserve the
> canonical-ordinal structure. Specifically:
>   1. `has_ties == False`  (no repeated values in either player's cardinal
>      payoff vector, so the ordinal rank 1..4 is well-defined).
>   2. `L1(cardinal) == L1(canonical)` for both players, with both
>      well-defined (no L1 ties on either side, ordinal or cardinal).
>
> Equivalently: the game's strategic skeleton (pure NE, iterated dominance,
> Level-1 best-response) is identical between its cardinal Griffiths form
> and its canonical Bruns/Robinson-Goforth form.

## Counts (this run)

- Griffiths total games: 1208
- After dropping `has_ties=True`: 832 (dropped 376)
- CLEAN after L1 filter: **279** (further dropped 553)
- Canonicals with at least one clean rowplayer-matching game: **61 / 144**

## Tables

### `equivalence_per_canonical.csv` — 144 rows

One row per Bruns/Robinson-Goforth canonical class. Columns include:

- Bruns canonical features: `canonical_id`, `bruns_name`, `bruns_long_name`,
  `canonical_p1`, `canonical_p2`, `canonical_8vec`, `nash_count`,
  `dominance_level`, `is_symmetric`, `canon_l1_p1`, `canon_l1_p2`.
- Nagel perspective (the unique perspective mapping to this canonical):
  `nagel_p_id`, `nagel_p_paired`, `nagel_perspective`, `nagel_matrix_code`,
  `nagel_lk_type` + description, `nagel_emp_class` + description,
  `nagel_rgg_class` + description, `nagel_swap_sr/sc`,
  `nagel_role_relative_to_canonical`, `nagel_frac_choose_A`,
  `nagel_frac_choose_act0_canonical`, `nagel_entropy_binary/4outcome`,
  `nagel_utility_efficiency`, `nagel_quality_level`, `nagel_n_pure_NE`,
  `nagel_p1_has_dominant`, `nagel_p2_has_dominant`.
- Clean Griffiths aggregate (rowplayer-side matches this canonical):
  `clean_grif_n_games`, `clean_grif_p1_mean`, `clean_grif_p2_mean`,
  `clean_grif_p1_std`, `clean_grif_p2_std`, `clean_grif_game_ids`
  (semicolon-joined list of Griffiths game_ids contributing).

### `equivalence_per_game.csv` — 78 rows

Player-swap-collapsed view. `game_id = min(p_id, p_paired)` so game numbers
run 1..78. Columns include:

- Game identity: `game_id`, `p_id_x` (= game_id), `p_id_y` (paired),
  `is_symmetric`.
- The two paired canonicals: `canonical_x`, `canonical_y`, `bruns_name_x/y`,
  `bruns_long_name_x/y`, `canonical_p1_x/y`, `canonical_p2_x/y`,
  `nash_count`, `dominance_level`, `canon_l1_p1`, `canon_l1_p2`.
- Both Nagel perspectives: `nagel_perspective_x/y`, `lk_type_x/y`,
  `emp_class_x/y`, `rgg_class_x/y`, `frac_choose_A_x/y`, `nagel_p1`, `nagel_p2`
  (canonical-aligned rates), `entropy_binary_x/y`.
- Clean Griffiths aggregate combining BOTH directions (rowplayer matches `cx`
  contributes `(rp, cp)`, rowplayer matches `cy` contributes reflected
  `(cp, rp)`): `clean_grif_n`, `clean_grif_p1/p2_mean`, `clean_grif_p1/p2_std`,
  `clean_grif_game_ids`, and `nagel_grif_gap` (Euclidean distance between
  the Nagel point and Griffiths centroid in X frame).

### `equivalence_clean_griffiths.csv` — 279 rows

Long-form. One row per CLEAN Griffiths game (both rowplayer and colplayer
rows merged into a single record). Columns include:

- Griffiths identity: `game_id`, `unique_id_rowplayer`,
  `unique_id_colplayer`, `topology_raw`.
- Cardinal & ordinal payoffs (rowplayer side): `cardinal_p1_rowplayer`,
  `cardinal_p2_rowplayer`, `ordinal_p1_rowplayer`, `ordinal_p2_rowplayer`.
- Empirical rates (raw + canonical-aligned, for both seats):
  `up_choice_rowplayer`, `up_choice_canonical_rowplayer`,
  `up_choice_colplayer`, `up_choice_canonical_colplayer`.
- Canonical identification (both sides):
  `canonical_id_rowplayer`, `bruns_name_rowplayer_side`,
  `canonical_id_colplayer`, `bruns_name_colplayer_side`,
  `swap_sr_rowplayer`, `swap_sc_rowplayer`,
  `swap_sr_colplayer`, `swap_sc_colplayer`.
- Canonical structural features: `nash_count`, `dominance_level`,
  `is_symmetric`.
- Nagel correspondence (joined via `canonical_id_rowplayer`):
  `nagel_p_id`, `nagel_p_paired`, `nagel_perspective`, `nagel_lk_type`,
  `nagel_emp_class`, `nagel_rgg_class`, `nagel_frac_choose_A`,
  `nagel_frac_choose_act0_canonical`, `nagel_entropy_binary`.
