# Taxonomy harmonization tables — Bruns / Nagel / Griffiths

Generated by `scripts/build_taxonomy_tables.py`. Read-only over `src/games.py`,
`datasets/nagel/perspective_info.csv`, and
`datasets/griffiths/games2p2k_main griffith emke.csv`.

## Schema

```
                       canonical_master.csv (144)
                                |
                                | canonical_id
            ___________________ |_____________________
           |                    |                     |
  bruns_to_canonical    nagel_to_canonical    griffiths_to_canonical
       (144)                  (144)                 (2,416)
```

The hub is the 144 Robinson-Goforth canonical classes (row x col swap orbits
of strict-ordinal 2x2 games). Every Bruns name is one canonical class. Every
Nagel perspective and every (non-tied) Griffiths row maps to one canonical via
`(swap_sr, swap_sc)`. Two joins through the hub answer every cross-taxonomy
question.

## Tables

### `canonical_master.csv` — 144 rows

| Column | Type | Description |
|---|---|---|
| `canonical_id` | int 1..144 | Synthetic primary key, lex order of `bruns_name`. |
| `bruns_name` | str | Bruns abbreviation (e.g. `PdPd`, `BaHr`). |
| `canonical_p1` | str | P1 4-vector `AA,AB,BA,BB` (ordinal 1-4). |
| `canonical_p2` | str | P2 4-vector `AA,AB,BA,BB`. |
| `canonical_8vec` | str | Concatenation, useful as a hash key. |
| `nash_count` | int | Pure-strategy NE count. |
| `dominance_level` | int 0..2 | `iesds_depth` — rounds of iterated strict dominance. |
| `is_symmetric` | bool | `player_swap(canonical) == canonical` under some `(sr,sc)`. |
| `bruns_long_name` | str | E.g. `PrisonerDilemma` (often empty). |

### `bruns_to_canonical.csv` — 144 rows

Trivial identity mapping `bruns_name -> canonical_id`. Emitted for symmetry.

### `nagel_to_canonical.csv` — 144 rows

| Column | Description |
|---|---|
| `p_id` | Nagel perspective id 1..144. |
| `p_paired` | Paired perspective (= `p_id` for symmetric). |
| `is_symmetric` | Nagel's flag (cross-checked against the master). |
| `lk_type` | Nagel level-k label. |
| `emp_class` | Rapoport-Guyer-Gordon empirical class. |
| `frac_choose_A` | Raw human row-player rate. |
| `canonical_id` | Master FK. |
| `swap_sr`, `swap_sc` | Bools — apply to align Nagel's encoding with canonical. |
| `role_relative_to_canonical` | `P1` for all rows in this build (see semantics below). |
| `frac_choose_act0_canonical` | `(1 - frac_choose_A) if swap_sr else frac_choose_A`. |

### `griffiths_to_canonical.csv` — 2416 rows (752 with ties, 1664 matched)

| Column | Description |
|---|---|
| `unique_id` | Griffiths row id 1..2416. |
| `game_id` | Game id (each game has 2 rows: `rowplayer`, `colplayer`). |
| `role` | `rowplayer` or `colplayer`. |
| `topology_raw` | Griffiths topology label (e.g. `('dilemma','hero')`). |
| `up_choice` | Raw human Up-choice rate. |
| `has_ties` | True if either player's cardinal vector has tied values. |
| `cardinal_p1`, `cardinal_p2` | Cardinal payoffs `AA,AB,BA,BB`. |
| `ordinal_p1`, `ordinal_p2` | Ordinalized 1-4 ranks (empty if `has_ties`). |
| `canonical_id` | Master FK; null if `has_ties`. |
| `swap_sr`, `swap_sc` | Alignment swaps; null if `has_ties`. |
| `role_relative_to_canonical` | `P1` for matched rows. |
| `up_choice_canonical` | `(1 - up_choice) if swap_sr else up_choice`. |

## Worked examples

### Bruns -> Nagel: which Nagel perspective is `PdPd`?

```python
m = pd.read_csv("canonical_master.csv")
n = pd.read_csv("nagel_to_canonical.csv")
cid = m.loc[m.bruns_name=="PdPd", "canonical_id"].iloc[0]   # = 131
n.loc[n.canonical_id==cid, ["p_id","swap_sr","swap_sc","frac_choose_act0_canonical"]]
# -> p_id=57, swap_sr=True, swap_sc=True, frac_choose_act0_canonical=0.3215
```

The raw `frac_choose_A` for Nag_057 is 0.6785, but Nagel's
A/B labels are inverted relative to Bruns' canonical encoding for this class
(both swaps are True), so the canonical-frame rate of choosing the row player's
canonical action 0 is `1 - 0.6785 = 0.3215`.

### Nagel -> Griffiths: which Griffiths games match Nag p_id=69?

```python
g = pd.read_csv("griffiths_to_canonical.csv")
cid = n.loc[n.p_id==69, "canonical_id"].iloc[0]
g.loc[(g.canonical_id==cid) & (~g.has_ties), ["game_id","role","up_choice_canonical"]]
```

This returns up to two rows per matching Griffiths `game_id` — one per role.
For asymmetric games the rowplayer and colplayer rows of a single `game_id`
land on **different** `canonical_id`s (related by `player_swap`); for symmetric
games both roles share one `canonical_id`. Filter on `role=="rowplayer"` to
align with row-player human action rates.

### Griffiths -> Bruns: what is Griffiths game_id=1's Bruns name (rowplayer view)?

```python
row = g.loc[(g.game_id==1) & (g.role=="rowplayer")].iloc[0]
m.loc[m.canonical_id==row.canonical_id, "bruns_name"].iloc[0]
```

## `role_relative_to_canonical` semantics

Bruns' 144 canonicals enumerate every strict-ordinal 2x2 game **up to
`(row_swap, col_swap)`**, *not* up to player swap. The 144 split into
12 strategically-symmetric self-paired canonicals + 132 asymmetric canonicals
forming 66 player-swap-paired pairs.

In this build every match resolves via the direct `(sr, sc)` phase, so
`role_relative_to_canonical = "P1"` for every matched row in both
`nagel_to_canonical` and `griffiths_to_canonical`. The `P2` fallback in
`find_match` is a defensive guard that should never fire given the master is
the full 144-class enumeration.

When comparing LLM-as-row-player behaviour to human row-player behaviour, use
`frac_choose_act0_canonical` (Nagel) or `up_choice_canonical` from the
`rowplayer`-side Griffiths row. The `colplayer` Griffiths row of the same
`game_id` is the *paired* canonical (different `canonical_id` for asymmetric
games); use it when comparing LLM-as-column-player behaviour.

## `dominance_level` choice

`dominance_level` here is `iesds_depth` from
`scripts/compute_game_features.py` — the number of rounds of iterated
elimination of strictly dominated strategies (0, 1, or 2 for a 2x2 game).
This is distinct from `dominance_profile` in
`datasets/processed/game_features.csv`, which counts how many players have a
strictly dominant strategy and uses an inverted 0/1/2 encoding (0 = both
dominant, 2 = neither). The two columns measure different things.

## Counts (this run)

- Master: 144 canonicals; 12 symmetric, 132 asymmetric.
- Master `nash_count` distribution: {0: 18, 1: 108, 2: 18}. The 18 zero-NE classes
  are Robinson-Goforth's cyclic-best-response cases (matching-pennies-style
  ordinal games); the 18 two-NE classes have two pure-strategy equilibria
  (coordination/anti-coordination structures); 108 have a unique pure NE.
- Nagel mapping: 144 rows, all with a non-null `canonical_id` (every
  Bruns canonical appears in Nagel — Nagel's 144 perspectives are bijective
  with the master).
- Griffiths mapping: 2416 rows; 752 with `has_ties=True`
  (~31%); 1664 matched to a canonical;
  126 of 144 canonical classes are covered by at least
  one Griffiths row; 832 unique `game_id`s have at least one
  matched canonical (each game contributes up to two distinct canonicals via
  its rowplayer/colplayer rows).
